# **Heart Disease Detection Using Retinal Image Scanning**

This repository contains the implementation of a machine learning project aimed at detecting heart disease risk using retinal image analysis. The project leverages advanced image preprocessing techniques, feature extraction, and a Recurrent Neural Network (RNN) with AdaBoost for classification. It also includes a web application for user-friendly interaction.

## **Introduction**

Heart disease is a leading cause of mortality worldwide. This project explores a non-invasive method of detecting early heart disease risk by analyzing retinal images. Vascular changes in the retina can serve as indicators of cardiovascular health, and this system automates the detection process to assist medical professionals.

---

## **Features**

- **Image Preprocessing**: Enhances retinal images using techniques like contrast enhancement, noise removal, and segmentation.
- **Feature Extraction**: Derives key vascular features such as vessel diameter, tortuosity, and branching angles.
- **Machine Learning Model**: Implements an RNN with AdaBoost for improved classification performance.
- **Web Application**: User-friendly interface for uploading images and viewing predictions.
- **Real-Time Results**: Provides diagnostic results with confidence scores.
- **Scalable Design**: Ready for deployment on cloud platforms for widespread use.

---

## **System Architecture**

The system consists of the following components:
1. **Frontend**: For user interaction and image upload.
2. **Backend**: Handles image processing, model inference, and API integration.
3. **Database**: Stores user data, images, and prediction results.
4. **Model**: RNN combined with AdaBoost for accurate classification.
5. **Deployment Platform**: Hosted on AWS/Heroku for seamless access.

## Dataset
The project uses publicly available retinal image datasets such as:
- DRIVE: Digital Retinal Images for Vessel Extraction
- STARE: Structured Analysis of the Retina
- CHASE_DB1: Child Heart and Health Study in England
These datasets contain labeled retinal images that are processed for feature extraction and model training.

## Results
- Accuracy: Achieved an accuracy of ~95% on testing data.
- Precision: High precision in detecting abnormal cases, minimizing false positives.
- Recall: Robust recall for identifying heart disease indicators.
- Visualization: Detailed output of segmented vascular features and classified results.
